DIY Elements is a kit that lets users customize their home screen, built from dynamic templates and layered motion. The widgets mainly cover weather status, personalized stickers, signatures, and more.

I led the design and the motion work for the elements and widgets, including the default neon, holiday, and realistic-style element sets.

The craft challenge in a DIY kit isn't any single element — it's the system. Every sticker, weather state, and signature is built as a layered, loopable composition on a shared timing language, so whatever combination a user stacks together still moves in rhythm instead of fighting itself.

That's really the point of the project: handing the motion language over. Users pick, stack, and place — and the result still feels designed.
